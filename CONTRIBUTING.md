# Contributing

Issues and focused pull requests are welcome. Before submitting code, please
open an issue so the change can be aligned with the public API contract and SDK
scope.

By submitting a contribution for inclusion in this repository, you represent
that you have the right to submit it and agree that it is provided under the
Apache License, Version 2.0, without additional terms or conditions. Mark a
communication conspicuously as `Not a Contribution` if it is not intended for
inclusion.

Contributions must preserve authentication, tenant isolation, and the reviewed
public OpenAPI boundary. Run the unit tests, formatting checks, and isolated
Docker smoke test before requesting review.
